# Cantrip Evaluation — for Selanar Durothil

Two-axis rating (same scales as the feat lists) of every wizard-list cantrip in the RAW mirror. Fable pass, 2026-07-25.

## Cantrip economy (what we're filling)

| Slot | Count | Notes |
|---|---|---|
| Wizard class | 3 at L1 → 4 at L4 → 5 at L10 | **One swappable every long rest** |
| High Elf lineage | 1 (default Prestidigitation) | **Swappable every long rest** for any wizard cantrip |
| Spellfire Spark | Sacred Flame | Fixed; also castable as a bonus action Prof/day |

Five cantrips at L1, **two of which float daily** — so "picks" here means the stable core; the floaters let him tune utility per adventuring day. That's a luxury most wizards don't have; the tiering below weights *stable-slot worthiness* accordingly.

## Scope

All wizard-list cantrips per the class-source lookup: 24 XPHB entries (2024 core — including absorbed reprints of Toll the Dead, Mind Sliver, Thunderclap and the new Elementalism) + the TCE quartet (Booming Blade, Green-Flame Blade, Sword Burst, Lightning Lure — 2014-era, table-legal). The XGE elemental-utility set (Shape Water, Mold Earth, Control Flames, Gust, Create Bonfire, Frostbite, Infestation) exists as 2014 content but was functionally superseded by Elementalism in 2024 and none earns a stable slot — surveyed, named, set aside.

**Levers:** the radiant/prismatic-light theme; the pending reskins (Echoing Light Blade = BB, Spellfire Blade = GFB); Bladesong making weapon attacks INT-based from L3; Extra Attack (L6) letting one attack be an action-cantrip; the visible-casting house rule (**somatic-only spells can be cast without a sound** — verbal ones can't be whispered); Elven Accuracy (planned L4) rewarding *attack-roll* cantrips whenever advantage exists; Spellfire Adept (planned L12) rewarding **radiant spell damage**.

## C/D — surveyed, dismissed

**Thunderclap** (CON-save AoE, loud in an intrigue game, Sword Burst is better imagery), **Acid Splash**, **Poison Spray** (poison = most-resisted damage type in the game), **Friends** (rides CHA 7 *and* ends with the target knowing — a diplomatic incident generator), **Mending** (off-camera practicality per house rules), **Dancing-Lights-style XGE utilities** (Shape Water, Mold Earth, Control Flames, Gust, Create Bonfire, Frostbite, Infestation — superseded or off-theme).

## Recommended loadout

**At L1** (3 class + lineage + feat):
- Class (stable): **True Strike** — the combat engine and the awakening-scene cantrip
- Class (stable): **Booming Blade** — the second blade rider (as Echoing Light Blade if approved)
- Class (floater): **Mind Sliver** by default; swap to **Message / Minor Illusion / Mage Hand** on intrigue days
- Lineage (floater): **Light** by default (the advantage engine); swap to **Prestidigitation** on court days
- Feat (fixed): **Sacred Flame** as "Spellfire Flame"

**Growth:** L4 → **Green-Flame Blade** (Spellfire Blade). L10 → utility consolidation (promote Minor Illusion or Message to stable; or Toll the Dead if ranged damage has been lacking).

Note the deliberate redundancy *avoidance*: True Strike, BB, and GFB all replace the same attack — but their riders answer different situations (raw radiant vs. movement-punish vs. cleave), and from L6 Extra Attack lets a cantrip ride alongside a weapon swing, so the diversity pays.
